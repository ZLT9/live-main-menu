# Live Main Menu

An experimental Minecraft mod that replaces the vanilla title screen panorama with a live, real-time view of a world.

Name a singleplayer world "LiveMainMenu" and the mod will load it automatically for the title screen.

Get it on [Modrinth](https://modrinth.com/mod/live-main-menu).
